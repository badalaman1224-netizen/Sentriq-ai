# Sentriq AI

Sentriq AI is a UPI fraud detection web application designed to help users identify potentially suspicious transactions through a simple dashboard.

## Features
- Transaction risk analysis interface
- Screenshot analysis interface
- Fraud alerts dashboard
- Beneficiary management
- Reports and settings

## Technologies Used
- HTML
- CSS
- React.js
- JavaScript
- LocalStorage

## Project Status
Frontend development is in progress. Backend integration and actual fraud detection logic will be added in future updates.

## Future Plans
- Node.js backend
- Database integration
- Improved fraud detection logic
